La cabaña de Lucía

Ejemplo de video narrado en formato vertical, con una ilustración original estilo cómic separada en capas. Activa y desactiva los efectos para ver cuánto aporta cada uno además del parallax.

frame 000 / 360 · 30 fps

Efectos

    La ilustración viene separada en capas: cielo, montañas, árboles, cabaña, personaje y primer plano. Con una imagen plana solo se pueden hacer zoom y parallax. Con capas se pueden animar las luces, partes del personaje y efectos entre una capa y otra.

    Así se hace en Remotion

    // Todo depende solo del número de frame, así Remotion
// puede renderizar frames en paralelo y salen iguales
const frame = useCurrentFrame();

// Humo: cada bocanada tiene una edad cíclica
const humo = [...Array(26)].map((_, i) => {
  const t = ((frame + i * 6) % 150) / 150;
  return { y: 560 - 170 * t, r: 8 + 42 * t,
           alpha: 0.5 * (1 - t) };
});

// Linterna que parpadea con ruido (@remotion/noise)
const brillo = 0.85 +
  0.1 * noise2D('linterna', frame * 0.1, 0);

// Relámpago sincronizado con la palabra "noche"
const flash = interpolate(frame - inicio('noche'),
  [0, 2, 10], [0, 1, 0],
  { extrapolateLeft: 'clamp', extrapolateRight: 'clamp' });
